# タイヤ交換記事 CTR改善リライト案

**対象記事**: `/content/posts/tire-replacement-2022-7-15.md`
**現在のパフォーマンス**: 表示回数12,389 / CTR 0.69% / クリック86件
**改善目標**: CTR 2.0%以上（クリック数247件以上）

---

## 📊 現状分析

### 現在のtitle/description
- **title**: "タイヤ交換の費用と選び方｜料金目安と厳選4本"
- **description**: "ロードバイク・クロスバイクのタイヤ交換費用の目安は1本2,000円〜8,000円。5,000円以上のミドルグレードがコスパ最強。交換時期の目安や岡山のcycleZスタッフが実際に使っているおすすめタイヤ4選を紹介します。"

### 問題点
1. **地域性の欠如**: タイトルに「岡山」が入っていない→ローカル検索で不利
2. **信頼訴求が弱い**: 「専門店」「実費公開」「スタッフ実使用」などの体験要素が title に出ていない
3. **価格帯が曖昧**: 「2,000円〜8,000円」は範囲が広すぎて検索者の不安を解消できていない
4. **クリック動機が不明確**: 「なぜこの記事を読むべきか」が description から伝わらない

### 流入KW（想定）
- 自転車タイヤ交換値段（表示613 / CTR 0.16%）
- 自転車タイヤ交換料金
- クロスバイクタイヤ交換値段（表示108 / CTR 0%）
- ロードバイク タイヤ交換 費用
- タイヤ交換 岡山

## 🎯 最終推奨

**【案A】を採用すべき理由**:

1. **GSCデータとの整合性**
   - 「自転車タイヤ交換値段」（表示613）「クロスバイクタイヤ交換値段」（表示108）が実際に流入KW
   - 検索者は「値段・料金」を最も知りたがっている→title冒頭に配置で CTR 向上

2. **地域性の強化**
   - 「岡山 自転車屋」（表示109 / CTR 0% / 順位7.6）で現在流入ゼロ
   - title に「岡山の専門店」、description に「岡山市北区」を入れることでローカル検索でもヒット

3. **E-E-A-T（経験・専門性・権威性・信頼性）の担保**
   - 「スタッフ仙田が通勤で3年使った」は記事内の実体験を description で先出し
   - 「実費公開」で透明性を訴求→「この店信頼できそう」と思わせる

4. **CTR改善の即効性**
   - 表示回数12,389は十分→title/description 変更だけで即効性が高い
   - 競合記事（大手ECサイトの商品一覧ページ等）は地域性・体験要素が弱い→差別化できる
