# 「ホイール変えたらこんなに違うんですね」

先日、60代のお客様が購入後にわざわざ来店してくださいました。

「ヒルクライムが楽になった」「向かい風でも30km/h巡行ができた」と、嬉しそうに報告してくれたんです。前回は出せなかったスピードが、普通に出る。それが嬉しくて、走り終わってすぐ店に寄ってくれた。

要は **「ホイールを変えるだけで、同じ脚力でも走りが別物になる」** です。

## きっかけはサイクルイベントへの参加

このお客様は、サイクルイベントに参加するためにロードバイクをグレードアップしたいという相談で来店されました。

それまで乗っていたのはアルミフレームのロードバイク。長年乗ってきて不満はないけれど、イベントに出るならもう少し走れる機体が欲しい。予算は50万円前後。

## 型落ちモデル＋カーボンホイールという選択肢

50万円あれば、最新モデルのミドルグレードを1台買うこともできます。でも今回は違う提案をしました。

**SCOTTのロードバイクの型落ちモデル＋カーボンホイール**。合計で約50万円。

型落ちといっても性能が落ちるわけではありません。前年モデルはカラーやマイナーチェンジの違いがあるだけで、フレームの基本設計は同じ。その分、価格が下がる。浮いた予算をホイールに回せば、同じ50万円でもトータルの性能は大きく変わります。

## ホイール代20万円は高いのか

カーボンホイールの価格帯は、おおよそ15〜30万円。20万円と聞くと「ホイールだけでそんなに？」と感じる方が多いです。

正直、カタログで見ているうちは高く感じます。

でも、自分の自転車につけて走ると、その理由がわかる。お客様も同じことを言っていました。

### アルミホイールとカーボンホイールの違い

| 項目 | アルミホイール | カーボンホイール |
|------|-------------|---------------|
| 重量 | 1,700〜2,000g前後 | 1,300〜1,500g前後 |
| 剛性 | 標準的 | 高い（踏んだ力がダイレクトに伝わる） |
| 空力 | リムハイトが低めで空力効果は少ない | リムハイトが高く、巡行速度の維持が楽 |
| 価格帯 | 3〜8万円 | 15〜30万円 |

数字だけ見ても実感が湧きにくいと思います。でも、重量で400〜500g軽くなり、リムハイトが高くなることで、特に**登りと向かい風**で明確な差が出ます。

## 実際に何が変わったのか

このお客様が体感した変化は、具体的にこうでした。

**1. フレームの違い（アルミ → カーボン）**

アルミフレームからSCOTTのカーボンフレームになっただけで、乗り心地が変わった。路面からの振動が柔らかくなり、長時間乗っても疲れにくい。これだけでも十分な変化です。

**2. ホイールの違い（アルミ → カーボン）**

フレームの変化に加えて、ホイールも変わったことで走りが別次元になった。

- **ヒルクライムが楽になった** — ホイールが軽くなった分、登りで脚が回る
- **向かい風でも30km/h巡行** — リムハイトの高いカーボンホイールは空力が良く、前回は出せなかった速度が維持できるようになった

同じ脚力で、出せる速度が変わる。これがホイール交換の最大の効果です。

## ロードバイクのアップグレードで一番効くのはホイール

フレーム、コンポーネント、ホイール。ロードバイクのパーツの中で、**走りの変化が一番体感しやすいのはホイール**です。

フレーム交換は車体ごと買い替えることになります。コンポーネント（変速機やブレーキ）のグレードアップは操作性は良くなるけれど、速さへの影響は限定的。

ホイールは「軽さ」「剛性」「空力」の3つを一度に変えられる。だから体感の差が大きい。

## 予算50万円のアップグレードプランとして

今回のケースを整理すると：

| 項目 | 内容 |
|------|------|
| 以前の車体 | アルミフレームのロードバイク |
| 新車体 | SCOTT カーボンロードバイク（型落ちモデル） |
| ホイール | カーボンホイール |
| 合計予算 | 約50万円 |
| 体感変化 | ヒルクライムが楽、向かい風30km/h巡行 |

最新モデルにこだわらず型落ちを選ぶことで、フレームとホイールの両方をカーボンにできた。結果として、予算内で最大限の性能アップを実現しています。

お客様も「お得になった」と喜んでいました。実際、同じ予算で最新モデルだけを買うより、走りの変化は大きかったはずです。
