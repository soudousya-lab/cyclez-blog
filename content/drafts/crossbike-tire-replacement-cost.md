# クロスバイクのタイヤ交換、実際いくらかかる？

「そろそろタイヤ変えた方がいいですよ」とショップで言われて、真っ先に気になるのは値段ですよね。

クロスバイクのタイヤ交換って、ロードバイクと何が違うのか。前と後ろで値段が変わるのか。ネットで買って持ち込みはできるのか。

今回は、うちの店で実際にクロスバイクのタイヤ交換をした場合の費用を、内訳まで全部見せます。

## タイヤ交換の費用内訳｜「タイヤ代＋工賃＋チューブ」の3つ

まず、タイヤ交換の費用は3つの要素で構成されています。

| 項目 | 目安 |
|------|------|
| タイヤ本体 | 【要確認】円〜 |
| チューブ | 【要確認】円 |
| 工賃（前輪） | 【要確認】円 |
| 工賃（後輪） | 【要確認】円 |

**後輪の工賃が前輪より高い理由**——後輪は変速機（ディレイラー）やチェーンを外す作業が入るためです。前輪はレバーを緩めてポンと外せますが、後輪はそうはいかない。

## ロードバイクのタイヤ交換とどう違う？

「[ロードバイクのタイヤ交換記事](/blog/tire-replacement-2022-7-15)」も以前書きましたが、クロスバイクとの大きな違いはタイヤの太さ。

| | ロードバイク | クロスバイク |
|---|---|---|
| タイヤ幅 | 23〜28mm | 28〜35mm |
| リム規格 | 700C | 700C（同じ） |
| 価格帯 | 5,000〜10,000円/本 | 【要確認】円/本 |

リム径が同じ700Cなので、実はロードバイク用の細いタイヤに変えることもできます。ただ、クロスバイクの用途（通勤・街乗り）を考えると、太めのタイヤのほうが段差に強く、パンクリスクも下がる。

## タイヤ交換のタイミング、こう判断してください

タイヤの寿命は距離で言うと**3,000〜5,000km**。

通勤で片道5km（往復10km）×週5日=月200km。年間だと約2,400km。つまり、通勤メインなら**1年半〜2年**で交換時期が来ます。

ただ、距離よりも先にダメになるパターンもあります。

- **側面にヒビが入っている** → 紫外線劣化。外保管だと1年で出ることも
- **タイヤの真ん中が平らになっている** → すり減り。雨の日にグリップが落ちる
- **最近パンクが増えた** → ゴムが薄くなってガラス片などが貫通しやすい状態

こういう症状が出たら、距離に関係なく交換のサインです。
