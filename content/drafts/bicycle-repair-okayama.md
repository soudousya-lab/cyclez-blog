# 岡山でスポーツバイクの修理、どこに持っていくか迷っていませんか？

「パンクした」「ブレーキの効きが悪い」「変速がおかしい」——こういうとき、ママチャリならどこの自転車屋さんでも対応してもらえます。

でも、ロードバイクやクロスバイクとなると話が変わります。

スポーツバイクはパーツの規格がママチャリとは違い、ディスクブレーキやカーボンフレームなど専門知識が必要な箇所も多い。一般的な自転車屋さんに持ち込んで「うちではちょっと…」と言われた経験がある方も少なくないはずです。

当店cycleZは岡山市北区島田本町にあるスポーツバイク専門店です。今回は、うちで対応できる修理メニューと工賃をまとめます。

## 「こんな症状」はすぐ持ってきてください

以下は、放置すると危険だったり、修理代が跳ね上がるパターンです。

- **ブレーキレバーがハンドルに当たるまで握れてしまう** → ワイヤー切れかパッド消耗。即修理
- **走行中にカチカチ・パキパキ音がする** → BB（ボトムブラケット）やペダルの緩み。放置するとフレーム側に影響
- **タイヤの側面にヒビが入っている** → バーストの危険。距離を問わず交換
- **雨の日にブレーキが全然効かない** → パッド交換やディスクのメンテが必要

「これってすぐ直したほうがいいのか、もう少し乗れるのか分からない」——そういう相談だけのご来店でも構いません。見て、状態をお伝えして、直すかどうかはお客さまに決めてもらいます。
