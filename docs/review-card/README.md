# クチコミ依頼カード（名刺サイズ）

店頭でお客様に手渡す、Googleクチコミの投稿ページへ誘導するカード。

## 生成

```bash
node scripts/gen-review-qr.mjs    # QRを作り直すとき（URLを変えた場合のみ）
node scripts/gen-review-card.mjs  # カードを作り直す
```

`npx` で `qrcode` を都度取得するため、初回や久しぶりの実行は数分かかる。

## 出力ファイル

| ファイル | 用途 |
|---|---|
| `review-card.pdf` | **入稿用**。97×61mm（仕上がり91×55mm＋塗り足し3mm） |
| `review-card.png` | 確認用（300dpi相当） |
| `review-card-guide.png` | 裁ち位置と文字安全域を重ねた確認用。**入稿しない** |
| `review-card.html` | 生成される中間HTML。確認用でコミットしない（.gitignore済み） |

デザインを変えるときは `scripts/gen-review-card.mjs` の中のHTML/CSSを直す。
`review-card.html` を直接編集しても次の生成で上書きされる。

## 入稿時の指定

- 仕上がりサイズ: 91×55mm（一般的な名刺サイズ）
- 塗り足し: 各辺3mm（PDFは塗り足し込みの97×61mm）
- 印刷: 片面カラー
- 用紙: マット系のほうがQRのテカリが出にくく読み取りやすい

## 刷る前の確認（必須）

1. `review-card.png` を等倍（91×55mm）で紙に出す
2. **実物のスマホカメラでQRを読み取り、Googleのクチコミ投稿フォームが開くことを確認する**
3. `review-card-guide.png` で、文字が水色の枠（文字安全域）の内側に収まっているか確認する

QRは28mm角・誤り訂正レベルM。1モジュールが約0.62mmになるので、
コンビニプリント程度の精度でも読み取れる。これ以上小さくしない。

## 中身のルール

カードとリンク先ページ（`/review`）には、**クチコミの文章・言い回し・語尾・定型文を用意しない**。

`/review` には単語のプルダウンがあるが、出るのは**単語だけ**で、文はお客様が自分で打つ。
プルダウンに入れてよいのは、事実（車種・したこと・きっかけ）と話題の名詞（接客・価格など）に限る。
**評価語（丁寧・親切・安心・おすすめ 等）は入れない** — 店が評価語を用意すると、
多数の投稿が同じ語彙から組まれて重複の痕跡になる。実際に2026-08-29時点のGBP84件のうち
8件が、旧文面生成ツール由来の同一文を共有していた。

★の初期選択、投稿先の出し分け、通信環境の案内も置かない（旧 `/review` の撤去理由）。
