## 🎯 レビュー依頼の2大タイミング

### 1. **納車時**（最優先タイミング）

**なぜ納車時が最適か:**
- 顧客満足度が最も高い瞬間（新車への期待・ワクワク感）
- スタッフとの信頼関係が構築できている
- 店舗滞在時間が長く、その場でQRコード読み取りが可能

**納車時フロー:**

```
① 納車説明完了後（写真撮影前）
   ↓
② スタッフ: 「お時間あれば、今日の体験を口コミにしていただけると嬉しいです」
   ↓
③ QRコード付きカードを手渡し
   ↓
④ 「こちらのQRコードから30秒で投稿できます。星の数だけでも大丈夫です」
   ↓
⑤ 納車記念写真撮影（納車後の余韻でレビュー依頼）
   ↓
⑥ 帰宅後フォローLINEで再依頼（3日後）
```

**声掛けスクリプト例:**

> 「〇〇さん、本日はありがとうございました！もしお時間があれば、今日の納車体験をGoogleの口コミに残していただけると、私たちとても励みになります。こちらのQRコードから30秒ほどで投稿できますので、よろしければお願いします。星の数だけでも構いません！」

**NGワード（規約違反）:**
- ❌ 「レビューを書いてくれたら割引します」（インセンティブ提供禁止）
- ❌ 「星5つでお願いします」（評価の強要禁止）
- ❌ 「悪い評価は書かないでください」（評価の操作禁止）

---

### 2. **メンテナンス完了時**

**なぜメンテ完了時が有効か:**
- 修理・調整で問題が解決した直後（満足度が高い）
- 定期的な接点があり、レビュー依頼を自然に繰り返せる
- 他店購入車でも来店→口コミに繋がる可能性

**メンテ完了時フロー:**

```
① メンテナンス内容説明・試走確認
   ↓
② お会計時にQRコード付きカードを添える
   ↓
③ 「また何かあればお気軽にどうぞ。よければ口コミもお願いします」
   ↓
④ 次回来店時に「前回の口コミありがとうございました！」と感謝
```

**声掛けスクリプト例:**

> 「今日の調整はいかがでしたか？もし満足いただけたら、Googleマップの口コミに一言残していただけると嬉しいです。このQRコードで簡単に投稿できます。次回の来店時の参考にもなりますので、ぜひお願いします！」

## 🛠️ 実施ツール

### A. QRコード付きカード（名刺サイズ）

**カード仕様:**
- サイズ: 名刺サイズ（55mm × 91mm）
- 用紙: マットコート紙180kg（高級感重視）
- 印刷: 両面カラー

**表面デザイン案:**

```
┌─────────────────────────┐
│                         │
│   📱 Google口コミ        │
│   ご協力お願いします     │
│                         │
│   [QRコード(大)]        │
│                         │
│   30秒で投稿完了！      │
│   星の数だけでもOK      │
│                         │
│   cycleZ                │
└─────────────────────────┘
```

**裏面デザイン案:**

```
┌─────────────────────────┐
│ あなたの声が、次の       │
│ サイクリストの選択を     │
│ 助けます 🚴             │
│                         │
│ 📍 岡山市北区津島南2-4-7 │
│ ☎ 086-250-0833          │
│ 🌐 cyclez.jp            │
└─────────────────────────┘
```

**QRコード生成URL:**
```
https://search.google.com/local/writereview?placeid=ChIJXXXXXXXXXXXXXXXXXXXX
```
（※ プレイスIDはGBP管理画面から取得）

**印刷発注先候補:**
- ラクスル（名刺サイズ 100枚 ¥1,500程度）
- プリントパック（短納期対応）

**配置場所:**
- レジカウンター（お会計時に手渡し）
- 納車デスク（納車説明時に手渡し）
- メンテナンススペース（作業完了時に手渡し）
- 店内ポップ（待合スペース・トイレ）

## 🚨 注意事項（Google規約遵守）

### ❌ 絶対にやってはいけないこと

1. **インセンティブ提供**
   - 「口コミ書いたら〇〇円割引」は規約違反
   - 「次回クーポンプレゼント」もNG

2. **評価の強要・誘導**
   - 「星5つでお願いします」は禁止
   - 「悪い評価は書かないで」も禁止

3. **偽装レビュー**
   - スタッフ・家族・友人に依頼して投稿させる
   - 業者に依頼して大量投稿

4. **ネガティブレビューの削除依頼**
   - 正当な批判は削除できない
   - 誹謗中傷のみGoogleに報告可能

### ✅ やるべきこと

1. **全ての口コミに返信**（24時間以内）
   - ポジティブレビュー: 感謝を伝える
   - ネガティブレビュー: 謝罪→改善策を提示

2. **自然な依頼**
   - 「もしよろしければ」「お時間があれば」のトーンで
   - 押し付けがましくない声掛け

3. **定期的な見直し**
   - 月次でフロー改善
   - スタッフ間でベストプラクティス共有
